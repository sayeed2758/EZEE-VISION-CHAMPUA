# EZEE VISION CHAMPUA — Phase 1

Premium public coaching website foundation built with Next.js and designed for free-tier Vercel deployment.

## Stack
- Next.js 14 App Router
- React 18
- CSS-only responsive UI
- No paid UI library required

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Build check
```bash
npm run build
```

## Deploy on Vercel
1. Create a GitHub repository and upload this project.
2. Import the repository into Vercel.
3. Framework preset: Next.js.
4. Build command: `next build` (Vercel can also auto-detect this).
5. No environment variables are required in Phase 1.

## Before publishing
Replace the demo phone/WhatsApp number (`+91 99999 99999`) and placeholder contact information in `app/page.js`.

Add real coaching photos, verified results, authentic testimonials and the exact Google Maps location before public launch.

The next phase can add a secure admin panel, Firebase authentication/database/storage, real enquiry storage, gallery management, updates, results and map/social settings without changing the public design direction.
